# FinOps Spend Analyzer

Cloud cost breakdown, waste detection and savings recommendations.

🚀 **Live app:** https://ziontechgroup.com/finops-spend-analyzer/

## Features
- Cost breakdown by service, team and environment
- Waste detection: idle resources, oversized instances, orphaned volumes
- Savings recommendations ranked by impact and effort
- Exportable FinOps report for finance and engineering
